# 🍩 Spinning ASCII Donut

A classic 3D spinning donut rendered entirely using ASCII characters in the terminal. This project uses the famous mathematical formula by Andy Sloane.

## 🚀 How to Run

Follow these steps to compile and run the donut on any Linux, macOS, or Windows WSL terminal.

### 1. Clone the repository
```bash
git clone https://github.com
cd spinning-donut
```

### 2. Compile the code
Use the `gcc` compiler to build the executable file:
```bash
gcc donut.c -o donut -lm
```

### 3. Run the animation
```bash
./donut
```

## 🛑 How to Stop
To close the animation and return to your terminal prompt, press **`Ctrl + C`**.
